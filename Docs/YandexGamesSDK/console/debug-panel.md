# Debug-панель

Снимок: https://yandex.ru/dev/games/doc/ru/console/debug-panel.md (2026-08-18).

Включение: консоль → «Открыть с debug-панелью», или `?debug-mode=16` в URL.

## Лоадер

| Индикатор | Значение |
| --------- | -------- |
| `W` | ждёт `YaGames.init()` |
| `IT` | актуальный лоадер (`/sdk.js` до `init`) — нужно для п. 1.19.1 |
| `IF` | старый лоадер — модерация отклонит |

## Game Ready

Фиолетовый → зелёный, когда вызван `ysdk.features.LoadingAPI.ready()`. Красный через 90 с — метод не вызван. Вызывать, когда меню/поле уже интерактивны, без своего экрана загрузки.
