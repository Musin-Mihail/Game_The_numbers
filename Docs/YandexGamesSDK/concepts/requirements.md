На странице описаны особенности требований к играм, хранящимся в [каталоге Яндекс Игры](https://yandex.ru/games/){.external}.

Проверка игр производится на окружениях, приближенных к пользовательским. Отсутствие найденного замечания на устройстве разработчика не является обоснованием для снятия замечания.

{% note info %}

Прохождение модерации не означает и не должно толковаться как заверение или иное подтверждение Яндекса в отношении соответствия игры требованиям законодательства какой-либо территории и/или отсутствия в отношении нее каких-либо нарушений прав или законных интересов третьих лиц.

{% endnote %}

<!-- source: ru/_includes/console/moderation.md -->
Игру проверят на соответствие [требованиям](https://yandex.ru/dev/games/doc/ru/concepts/requirements.md). Обычно [модерация](https://yandex.ru/dev/games/doc/ru/concepts/moderation.md) занимает 3−5 рабочих дней.

## Технические требования {#1}

<p class="hidden-text">Раздел 1.</p>

1. <span class="hidden-text">Пункт 1.1.</span> В игру встроен SDK Яндекс Игр. Подробнее см. в разделе [Подключение и использование](https://yandex.ru/dev/games/doc/ru/sdk/sdk-about.md). {#1-1}
2. <span class="hidden-text">Пункт 1.2.</span> Для запуска и использования не требуется регистрация или авторизация на сторонних сервисах. Допустима авторизация с Яндекс ID. [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/2.md#auth-add). {#1-2}

    1. <span class="hidden-text">Пункт 1.2.1.</span> Авторизация происходит только после осознанного действия пользователя — нажатия на специальную кнопку внутри игры. Предложение авторизации содержит понятный и ясный текст, который объясняет причину необходимости авторизации. [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/2.md#auth-offer). {#1-2-1}

    2. <span class="hidden-text">Пункт 1.2.2.</span> Реализован гостевой вход или возможность использования без авторизации. Внутренний прогресс при этом должен сохраняться. {#1-2-2}

3. <span class="hidden-text">Пункт 1.3.</span> При сворачивании страницы с игрой на десктопных и мобильных устройствах звук останавливается. [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/3.md). {#1-3}
4. <span class="hidden-text">Пункт 1.4.</span> Платежи производятся только через [SDK Яндекс Игр](https://yandex.ru/dev/games/doc/ru/sdk/sdk-purchases.md). Отсутствуют микротранзакции и любые внешние покупки. {#1-4}
5. <span class="hidden-text">Пункт 1.5.</span> (Упразднен, см. [пункт 4.1](#4-1).) {#1-5}
6. <span class="hidden-text">Пункт 1.6.</span> Игра должна соответствовать требованиям к тем видам устройств, которые указаны в заявке на публикацию. {#1-6}

    1. <span class="hidden-text">Пункт 1.6.1.</span> Для мобильных устройств: {#1-6-1}

        1. <span class="hidden-text">Пункт 1.6.1.1.</span> Игра находится в полноэкранном режиме во время игрового процесса или запуска. {#1-6-1-1}

        2. <span class="hidden-text">Пункт 1.6.1.2.</span> Если есть возможность ввода данных (например, никнейма игрока или названия документа) в поля, клавиатура автоматически показывается при нажатии на поле ввода. {#1-6-1-2}

        3. <span class="hidden-text">Пункт 1.6.1.3.</span> Визуальные элементы не деформируются и не растягиваются непропорционально при изменении ориентации экрана и/или изменении размера доступной области. Если игра имеет только одну ориентацию, необходимо выбрать соответствующее значение при заполнении черновика. В противоположной ориентации будет отображаться специальная заглушка о повороте устройства. {#1-6-1-3}

        4. <span class="hidden-text">Пункт 1.6.1.4.</span> (Упразднен.) {#1-6-1-4}

        5. <span class="hidden-text">Пункт 1.6.1.5.</span> Игра полностью управляется жестами. Механики управления можно дополнить использованием акселерометра мобильного устройства. {#1-6-1-5}

        6. <span class="hidden-text">Пункт 1.6.1.6.</span> В любых браузерах не отображается системный плеер, вызываемый игрой. [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/6.md). {#1-6-1-6}

        7. <span class="hidden-text">Пункт 1.6.1.7.</span> Отсутствует уведомление о WebGL при открытии игры. {#1-6-1-7}

        8. <span class="hidden-text">Пункт 1.6.1.8.</span> [Лонгтап](*longtap) по внутреннему полю игры не приводит к выделению поля или открытию контекстного меню. {#1-6-1-8}

    2. <span class="hidden-text">Пункт 1.6.2.</span> Для десктопных устройств: {#1-6-2}

        1. <span class="hidden-text">Пункт 1.6.2.1.</span> Активное поле растягивается по вертикали или горизонтали до края доступной области (без учета стики-баннеров). {#1-6-2-1}

        2. <span class="hidden-text">Пункт 1.6.2.2.</span> Длинная сторона активного поля превосходит короткую не более чем в два раза. {#1-6-2-2}

        3. <span class="hidden-text">Пункт 1.6.2.3.</span> Визуальные элементы не деформируются и не растягиваются непропорционально при изменении размера доступной области. {#1-6-2-3}

        4. <span class="hidden-text">Пункт 1.6.2.4.</span> Управление производится с помощью клавиатуры или мышки по умолчанию. {#1-6-2-4}

        5. <span class="hidden-text">Пункт 1.6.2.5.</span> В любых браузерах не отображается системный плеер, вызываемый игрой. [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/6.md). {#1-6-2-5}

        6. <span class="hidden-text">Пункт 1.6.2.6.</span> В игре не должно быть реализовано управление с помощью горячих клавиш, сочетание которых используется для выполнения определенных функций или команд в операционной системе или в приложениях. {#1-6-2-6}

        7. <span class="hidden-text">Пункт 1.6.2.7.</span> Взаимодействие с внутренним полем игры не приводит к выделению поля или открытию контекстного меню. {#1-6-2-7}

    3. <span class="hidden-text">Пункт 1.6.3.</span> Для телевизоров ([подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/6/3.md)): {#1-6-3}

        1. <span class="hidden-text">Пункт 1.6.3.1.</span> Игра занимает всю площадь экрана, доступен полноэкранный режим. {#1-6-3-1}

        2. <span class="hidden-text">Пункт 1.6.3.2.</span> Поддерживается управление с помощью стрелок на ТВ-пульте. Для полноценного прохождения игры достаточно управления стрелками пульта. {#1-6-3-2}

        3. <span class="hidden-text">Пункт 1.6.3.3.</span> Имеется поддержка нажатия кнопок **Back** и **ОК** на ТВ-пульте. {#1-6-3-3}

        4. <span class="hidden-text">Пункт 1.6.3.4.</span> Отсутствуют инап-покупки. {#1-6-3-4}

        5. <span class="hidden-text">Пункт 1.6.3.5.</span> Нет ссылок на другие игры разработчика. {#1-6-3-5}

7. <span class="hidden-text">Пункт 1.7.</span> Для корректной работы из любой точки мира в программном коде не используются абсолютные URL, ссылающиеся на серверы S3 Яндекса. {#1-7}
8. <span class="hidden-text">Пункт 1.8.</span> Размеры внутренних элементов, кнопок, графики адаптированы для отображения и взаимодействия так, чтобы исключить случайные нажатия и затруднения при нажатиях на элементы. {#1-8}
9. <span class="hidden-text">Пункт 1.9.</span> В играх с внутренним прогрессом (новые открытые уровни, рекорды, достижения, улучшения) сохранение изменений происходит сразу после действия игрока или по специальной кнопке сохранения. Обновление страницы не должно влиять на сохраненные данные. [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/9.md). {#1-9}

10. <span class="hidden-text">Пункт 1.10.</span> Игра корректно отображается, в том числе при изменении размера окна: {#1-10}

    1. <span class="hidden-text">Пункт 1.10.1.</span> Масштаб активного поля не выходит за рамки экрана, элементы не обрезаются. [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/10.md#cut). {#1-10-1}

    2. <span class="hidden-text">Пункт 1.10.2.</span> Отсутствует браузерная прокрутка страницы (системный скроллбар окна браузера) или swipe-to-refresh. При этом допустимо реализовать собственную прокрутку контента средствами игры. [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/10.md#scroll-swipe). {#1-10-2}

    3. <span class="hidden-text">Пункт 1.10.3.</span> Внутренние элементы и тексты не накладываются друг на друга и не перекрывают другие элементы. [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/10.md#overlap). {#1-10-3}

    4. <span class="hidden-text">Пункт 1.10.4.</span> Возможно управлять игрой одной рукой и постоянно находиться на основной сцене без дополнительных прокруток или смахиваний. Допускаются перемещения внутреннего игрового поля в стратегиях, ролевых играх и прочих жанрах с большим игровым полем. {#1-10-4}

11. <span class="hidden-text">Пункт 1.11.</span> Если вы используете облачные сохранения, необходимо указать это при заполнении черновика в специальном поле. {#1-11}
12. <span class="hidden-text">Пункт 1.12.</span> Подключена монетизация Рекламной сети Яндекса (РСЯ). [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/12.md). {#1-12}
13. <span class="hidden-text">Пункт 1.13.</span> Для внутренних покупок: {#1-13}

    1. <span class="hidden-text">Пункт 1.13.1.</span> Подключен [метод консумирования](https://yandex.ru/dev/games/doc/ru/sdk/sdk-purchases.md#check-purchases). [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/13.md#consummation). {#1-13-1}

    2. <span class="hidden-text">Пункт 1.13.2.</span> Портальная валюта определяется автоматически: название и иконка берутся из [SDK](https://yandex.ru/dev/games/doc/ru/sdk/sdk-purchases.md#product-characteristics). [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/13.md#currency-detection). {#1-13-2}

    3. <span class="hidden-text">Пункт 1.13.3.</span> Прогресс игры сохраняется на сервере и доступен для одного пользователя с разных устройств. [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/13.md#purchases-save). {#1-13-3}

    4. <span class="hidden-text">Пункт 1.13.4.</span> Все покупки внутри игры имеют обозначенную цифрами стоимость и указание портальной валюты. {#1-13-4}

    5. <span class="hidden-text">Пункт 1.13.5.</span> Изображение, название, состав и характеристики покупки, приобретенной пользователем, должны соответствовать параметрам, указанным в предложении о покупке. [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/13.md#purchase-correct). {#1-13-5}

    6. <span class="hidden-text">Пункт 1.13.6.</span> Список покупок в игре соответствует информации в [Консоли разработчика](https://games.yandex.ru/console){.external}: {#1-13-6}
        - Если на вкладке **Инап-покупки** есть активные покупки, они присутствуют в игре.
        - Если вкладка **Инап-покупки** пустая или покупки на ней неактивны, они отсутствуют в игре.

14. <span class="hidden-text">Пункт 1.14.</span> Нет технических сообщений, ошибок и вылетов, зависаний через некоторое время после начала использования или при определенных действиях пользователя. Например: поворачивание экрана, длительное нажатие на поле игры, жесты и смахивания, сворачивание браузера, открытие рекламы, переходы по истории браузера и другие способы взаимодействия. [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/14.md). {#1-14}
15. <span class="hidden-text">Пункт 1.15.</span> Игра имеет завершенный вид и не находится в процессе разработки или предварительного тестирования. [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/15.md). {#1-15}
16. <span class="hidden-text">Пункт 1.16.</span> Отсутствуют модификации контента и внешнего вида встраиваемых рекламных блоков. Запрещено имитировать рекламные блоки сервиса, например создавать кастомные полноэкранные блоки или [RV](*RewardedVideo) со своими кнопками. {#1-16}
17. <span class="hidden-text">Пункт 1.17.</span> (Упразднен.) {#1-17}
18. <span class="hidden-text">Пункт 1.18.</span> В игре отсутствуют любые технические способы ограничения работы игры из-за URL, на котором открыта игра. {#1-18}
19. <span class="hidden-text">Пункт 1.19.</span> Инициализация SDK Яндекс Игр и использование его методов производятся в строгом соответствии с документацией и требованиями к игре: {#1-19}

    1. <span class="hidden-text">Пункт 1.19.1.</span> SDK инициализируется строго так, как указано на странице [Подключение и использование](https://yandex.ru/dev/games/doc/ru/sdk/sdk-about.md). [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/19.md#sdk-initializing). {#1-19-1}

    2. <span class="hidden-text">Пункт 1.19.2.</span> В момент, когда пользователь уже может приступить к игре, должен быть произведен вызов метода `LoadingAPI.ready()` из [Game Ready](https://yandex.ru/dev/games/doc/ru/sdk/sdk-game-events.md#gameready). [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/1/19.md#gameready). {#1-19-2}

    3. <span class="hidden-text">Пункт 1.19.3.</span> Использование разметки геймплея опционально, при этом если методы `GameplayAPI.start()` и `GameplayAPI.stop()` используются в игре, то моменты отправки событий строго соответствуют описанным в разделе [Геймплей](https://yandex.ru/dev/games/doc/ru/sdk/sdk-game-events.md#gameplay). {#1-19-3}

    4. <span class="hidden-text">Пункт 1.19.4.</span> Отслеживание событий `game_api_pause` и `game_api_resume` опционально, при этом если методы `ysdk.on()` и `ysdk.off()` используются в игре, то логика обработки событий строго соответствует описанной в разделе [Пауза и возобновление игры](https://yandex.ru/dev/games/doc/ru/sdk/sdk-events.md#pause-resume). {#1-19-4}

20. <span class="hidden-text">Пункт 1.20.</span> Игра корректно запускается в браузерах и на платформах, которые подходят под выбранное в черновике окружение. Список браузеров и платформ: {#1-20}

    1. <span class="hidden-text">Пункт 1.20.1.</span> В браузерах: Яндекс Браузер, Google Chrome, Mozilla Firefox, Opera, Safari, мобильном приложении Яндекс. {#1-20-1}

    2. <span class="hidden-text">Пункт 1.20.2.</span> В операционных системах: Windows Vista, Windows 7, Windows 8, Windows 10, Mac OS X 10.6 и выше (Snow Leopard, Lion, Mountain Lion, Mavericks, Yosemite, El Capitan, Sierra, High Sierra и Mojave). {#1-20-2}

    3. <span class="hidden-text">Пункт 1.20.3.</span> В мобильных операционных системах: Android 5.0 и выше, iOS 9.0 и выше. {#1-20-3}

    4. <span class="hidden-text">Пункт 1.20.4.</span> На Android TV. {#1-20-4}

21. <span class="hidden-text">Пункт 1.21.</span> Размер всех файлов игры не превышает 100 МБ в разархивированном виде. {#1-21}
22. <span class="hidden-text">Пункт 1.22.</span> В корень архива добавлен файл `index.html`. В названиях файлов и папок не используются пробелы и русские символы. {#1-22}
23. <span class="hidden-text">Пункт 1.23.</span> В играх запрещено использование интерактивного искусственного интеллекта (ИИ). Допускается использование материалов внутри игры, которые были заранее сгенерированы с помощью ИИ. {#1-23}
24. <span class="hidden-text">Пункт 1.24.</span> Обновления игры должны сохранять ее основную концепцию. Запрещено загружать в качестве обновления совершенно другую игру. {#1-24}



## Требования к пользовательскому опыту {#2}

<p class="hidden-text">Раздел 2.</p>

1. <span class="hidden-text">Пункт 2.1.</span> Игра проработана с точки зрения содержания, удобства и качества игрового процесса. Сервис осуществляет внутренний контроль качества и имеет право отказать в публикации игр, не проходящих общую оценку качества. {#2-1}
2. <span class="hidden-text">Пункт 2.2.</span> В игре или полях сопроводительных описаний к ней представлено полное описание управления. {#2-2}
3. <span class="hidden-text">Пункт 2.3.</span> Игра соответствует заявленному жанру. {#2-3}
4. <span class="hidden-text">Пункт 2.4.</span> Игра соответствует минимум одному из критериев наличия игровых механик. [Подробнее](https://yandex.ru/dev/games/doc/ru/requirements/2/4.md). {#2-4}
